# ÉLÉGANCE | Events & Experiences

**Make Every Moment Timeless.**

ÉLÉGANCE is a luxury event management website designed to showcase elegant celebrations, professional event services, and premium event packages.

## ✨ Features

- Elegant and luxurious website design
- Home and About sections
- Event showcase: Weddings, Corporate Events, and Concerts
- Event planning services
- Silver, Gold, and Platinum packages
- Customer testimonial section
- Contact form design
- Responsive layout for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎨 Design

- Royal white, gold, and black color theme
- Smooth scrolling
- Hover animations and interactive cards
- Responsive layout
